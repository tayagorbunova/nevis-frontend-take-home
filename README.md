# Nevis — Frontend Home Assignment

**Live:** https://nevis-frontend-home-assignment.vercel.app

## Run it locally

You need Node.js 24.

```bash
npm install
npm run dev
```

Then open http://localhost:5173. The command starts both the page and the API (on port 3001).
